# ❓ Контрольные вопросы

## 1. Что такое Midnight Commander?

**Midnight Commander (MC)** — консольный двухпанельный файловый менеджер для операционных систем GNU/Linux.

## 2. Как запустить Midnight Commander?

Для запуска используется команда:

```bash
mc
```

## 3. Для чего используются две панели?

Две панели позволяют одновременно работать с содержимым двух каталогов и удобно выполнять операции копирования и перемещения.

## 4. Какая клавиша используется для просмотра файла?

```text
F3
```

## 5. Какая клавиша используется для редактирования файла?

```text
F4
```

## 6. Какая клавиша используется для копирования?

```text
F5
```

## 7. Какая клавиша используется для перемещения?

```text
F6
```

## 8. Какая клавиша используется для создания каталога?

```text
F7
```

## 9. Какая клавиша используется для удаления?

```text
F8
```

## 10. Для чего используется клавиша F9?

Клавиша `F9` открывает главное меню Midnight Commander.

## 11. Как найти файл по имени?

Для этого используется функция:

```text
Command → Find file
```

## 12. Что означает шаблон *.png?

Шаблон:

```text
*.png
```

означает поиск файлов с расширением `.png`.

## 13. Как выполняется поиск содержимого файлов?

В окне поиска указывается текст, который необходимо найти внутри файлов.

## 14. Что такое символическая ссылка?

Символическая ссылка — специальный объект файловой системы, содержащий путь к другому файлу или каталогу.

## 15. Что произойдёт с символической ссылкой после удаления целевого файла?

Символическая ссылка останется, но перестанет указывать на существующий объект.

## 16. Для чего используется функция «Размеры каталогов»?

Функция позволяет определить размер каталогов и занимаемое ими дисковое пространство.

## 17. Для чего используется FTP?

FTP используется для передачи файлов между компьютерами по сети.

## 18. Для чего используется SFTP?

SFTP предназначен для передачи файлов через защищённое соединение SSH.

## 19. Что показывает команда date?

Команда:

```bash
date
```

выводит текущую дату и время системы.

## 20. Что такое каталог /etc?

```text
/etc
```

— каталог, содержащий системные конфигурационные файлы Linux.

## 21. Что такое каталог /tmp?

```text
/tmp
```

— каталог для временных файлов.

## 22. Как завершить работу с Midnight Commander?

Для выхода используется клавиша:

```text
F10
```
