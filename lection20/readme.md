# 📚 Краткие теоретические сведения

Файлами в Linux считаются обычные файлы, каталоги и специальные файлы, соответствующие периферийным устройствам.

Файловая система Linux имеет иерархическую древовидную структуру.

### Основные каталоги Linux

| Каталог | Назначение |
|---|---|
| `/bin` | Исполняемые командные программы |
| `/tmp` | Временные файлы |
| `/usr` | Пользовательские программы и каталоги |
| `/etc` | Административные файлы и настройки |
| `/dev` | Специальные файлы устройств |

### Права доступа

В Linux существуют три уровня доступа:

1. **Владелец файла** — `u`
2. **Группа владельца** — `g`
3. **Остальные пользователи** — `o`

Основные права:

| Символ | Значение |
|---|---|
| `r` | чтение |
| `w` | запись |
| `x` | выполнение |
| `-` | право отсутствует |

Для просмотра атрибутов файла используется команда `ls -l`.

Для изменения прав доступа используется команда `chmod`.

Например:

`chmod go+x file.txt`

Эта команда добавляет право выполнения для группы и остальных пользователей.

## 5. Просмотр полной информации о файлах

Для просмотра полной информации о файлах используется команда:

`ls -l`

Команда позволяет увидеть:

- права доступа;
- количество связей;
- владельца файла;
- группу;
- размер файла;
- дату и время изменения;
- имя файла.

Пример:

`-rw-rw-r-- 1 abobi4 abobi4 24 Sep 9 02:27 f1.txt`

## 6. Изменение прав доступа

Добавим право выполнения для группы и остальных пользователей:

`chmod go+x f1.txt f2.txt merged.txt`

После изменения прав снова просмотрим атрибуты:

`ls -l`

После выполнения команды права доступа изменятся. У файлов появится право `x` для группы и остальных пользователей.

# ❓ Контрольные вопросы

## 1. Что считается файлами в ОС Linux?

В Linux файлами считаются обычные файлы, каталоги, а также специальные файлы, представляющие периферийные устройства.

---

## 2. Объясните назначение связей с файлами и способы их создания.

Связи позволяют обращаться к одному файлу из разных мест файловой системы под разными именами.

Для создания обычной связи используется команда:

`ln file1 file2`

Для создания символической связи используется команда:

`ln -s file1 file2`

---

## 3. Что определяет атрибуты файлов и каким образом их можно просмотреть и изменить?

Атрибуты определяют тип файла и права доступа владельца, группы и остальных пользователей.

Просмотреть атрибуты можно с помощью команды:

`ls -l`

Изменить права доступа можно командой:

`chmod`

Например:

`chmod go+x file.txt`

---

## 4. Какие методы создания и удаления файлов и каталогов Вы знаете?

Файл можно создать с помощью перенаправления:

`> file.txt`

Также файл можно создать командой:

`echo "text" > file.txt`

Удалить файл можно командой:

`rm file.txt`

Создать каталог:

`mkdir directory`

Удалить пустой каталог:

`rmdir directory`

---

## 5. В чем заключается поиск по шаблону?

Поиск по шаблону позволяет находить строки или файлы, соответствующие заданному образцу.

Для поиска используется команда `grep`.

Например:

`grep -l student *.txt`

Команда ищет текстовые файлы, содержащие последовательность `student`.

---

## 6. Какой командой можно получить список работающих пользователей и сохранить его в файле?

Для получения списка работающих пользователей используется команда:

`who`

Для сохранения результата в файл:

`who > users.txt`
