## 📖 Теоретические сведения
### Права доступа в Linux
В операционной системе Linux каждый файл и каталог имеют три уровня доступа:
1. Владелец (u — user) — пользователь, создавший файл;
2. Группа (g — group) — группа пользователей, к которой принадлежит владелец;
3. Остальные (o — others) — все остальные пользователи.
Для каждого уровня могут быть установлены следующие права:
| Символ | Значение |
|--------|----------|
| r | Чтение |
| w | Запись |
| x | Выполнение |
| - | Отсутствие права |
### Числовой способ задания прав
Каждое право имеет числовое значение:
| Право | Значение |
|-------|----------|
| r | 4 |
| w | 2 |
| x | 1 |
Итоговое значение права вычисляется суммированием чисел:
- rwx = 4 + 2 + 1 = 7
- rw- = 4 + 2 + 0 = 6
- r-- = 4 + 0 + 0 = 4
- --x = 0 + 0 + 1 = 1

## 🛠️ Ход выполнения работы
### 1. Создание каталога в корне файловой системы
Для создания каталога в корне файловой системы используется команда mkdir с указанием полного пути. В данном случае каталог создаётся непосредственно в корне (/).
Выполненная команда:
sudo mkdir /papka
Примечание: Для создания каталога в корне необходимы права суперпользователя, поэтому используется команда sudo.
---
### 2. Создание текстового файла file1 с содержимым
Внутри созданного каталога /papka необходимо создать текстовый файл file1 с содержимым «LINUX THE BEST».
Выполненные команды:
cd /papka
echo "LINUX THE BEST" > file1
Команда cd /papka выполняет переход в созданный каталог.
Команда echo "LINUX THE BEST" > file1 создаёт файл file1 и записывает в него указанную строку.
---
### 3. Создание текстового файла cat
Внутри каталога /papka создаётся второй текстовый файл с именем cat.
Выполненная команда:
touch cat
Команда touch создаёт пустой файл с указанным именем.
---
### 4. Объединение файлов file1 и cat в файл Copy
Для объединения содержимого двух файлов в один используется команда cat.
Выполненная команда:
cat file1 cat > Copy
Команда cat file1 cat > Copy читает содержимое файлов file1 и cat и записывает их в файл Copy. Если файл Copy не существует, он будет создан.
---
### 5. Проверка содержимого созданных файлов
Для проверки правильности выполнения предыдущих шагов выведем содержимое всех файлов.
Выполненные команды:
ls -l
cat file1
cat cat
cat Copy
Результат выполнения команд:
total 12
-rw-r--r-- 1 abobi4 abobi4 17 Sep 9 02:27 file1
-rw-r--r-- 1 abobi4 abobi4  0 Sep 9 02:30 cat
-rw-r--r-- 1 abobi4 abobi4 17 Sep 9 02:31 Copy
Содержимое файла file1:
LINUX THE BEST
Содержимое файла cat:
(пустой файл)
Содержимое файла Copy:
LINUX THE BEST
---
### 6. Настройка прав доступа для файла Copy
Согласно заданию, файлу Copy необходимо выдать следующие разрешения:
| Пользователь | Вид разрешений |
|--------------|----------------|
| Владелец (users) | rwx |
| Группа (groups) | rwx |
| Остальные (others) | --x |
Для изменения прав доступа используется команда chmod. В числовом формате права задаются следующим образом:
- rwx = 7 (4 + 2 + 1)
- rwx = 7 (4 + 2 + 1)
- --x = 1 (0 + 0 + 1)
Итоговое числовое значение: 771
Выполненная команда:
chmod 771 Copy
Разбор команды:
| Цифра | Категория | Права | Значение |
|-------|-----------|-------|----------|
| 7 | Владелец | rwx | Чтение, запись, выполнение |
| 7 | Группа | rwx | Чтение, запись, выполнение |
| 1 | Остальные | --x | Только выполнение |
---
### 7. Проверка установленных прав доступа
Для проверки правильности установки разрешений выполним команду ls -l и проанализируем вывод.
Выполненная команда:
ls -l Copy
Результат выполнения команды:
-rwxrwx--x 1 abobi4 abobi4 17 Sep 9 02:31 Copy
Анализ атрибутов файла Copy:
| Символы | Значение |
|---------|----------|
| - | Тип файла: обычный файл |
| rwx | Права владельца: чтение, запись, выполнение |
| rwx | Права группы: чтение, запись, выполнение |
| --x | Права остальных: только выполнение |
Вывод: Права доступа для файла Copy успешно установлены в соответствии с заданием.
