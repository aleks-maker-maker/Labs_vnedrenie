🛠️ Ход работы

1. Навигация по каталогам файловой системы

Для работы был открыт терминал с помощью сочетания клавиш:

Ctrl + Alt + T

---

📍 Команда "pwd"

Для определения текущего рабочего каталога была выполнена команда:

pwd

Результат:

/home/student

Команда "pwd" (print working directory) выводит полный путь текущего рабочего каталога.

---

📋 Команда "ls"

Для просмотра содержимого текущего каталога была выполнена команда:

ls

Результат:

Desktop
Documents
Downloads
Music
Pictures
Public
Templates
Videos

Команда "ls" (list directory contents) выводит список файлов и каталогов текущей директории.

---

👁️ Команда "ls -a"

Для просмотра всех объектов, включая скрытые файлы и каталоги, была выполнена команда:

ls -a

Результат:

.
..
.bash_history
.bash_logout
.bashrc
.config
Desktop
Documents
Downloads
Music
Pictures
Public
Templates
Videos

Параметр "-a" (all) позволяет отображать также скрытые объекты.

---

📂 Переход в каталог "/bin"

Для перехода в системный каталог "/bin" была выполнена команда:

cd /bin

После выполнения команды текущим рабочим каталогом стал:

/bin

Проверить это можно с помощью:

pwd

Результат:

/bin

---

📊 Результаты выполнения

Команда| Назначение| Результат
"pwd"| Определение текущего каталога| "/home/student"
"ls"| Просмотр содержимого каталога| Список каталогов пользователя
"ls -a"| Просмотр всех объектов| Отображены скрытые файлы
"cd /bin"| Переход в каталог| Текущий каталог "/bin"

---

💡 Краткое описание команд

"pwd"

Показывает полный путь текущего рабочего каталога.

"ls"

Показывает содержимое текущего каталога.

"ls -a"

Показывает все объекты каталога, в том числе скрытые.

"cd"

Позволяет перейти в другой каталог.

Пример:

cd /bin
